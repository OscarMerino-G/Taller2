# Taller2 :trollface:
### Integrantes
Oscar Merino

## Descripción
> El proyecto es un reproductor de música que carga la configuracion del mismo y la lista de canciones desde un archivo. Tiene las funciones básicas de un reproductor de música (saltar canción y volver a la canción anterior) y tiene las funciones que se encuentran en los servicios de streaming de musica (cola de canciones, crear lista de canciones e historial de canciones), ademas implementa las funciones necesarias para poder mostrar un ranking de canciones y artistas

# Compilar con el siguiente codigo
> g++ -std=c++14 main.cpp src/nucleo/* .cpp src/clases/* .cpp src/Estructura_Datos/* .cpp -o reproductor.exe
> (quitar espacios despues de asteriscos)

# Ejecutar con 
> reproductor.exe
